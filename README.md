# Zastra

Однокнопочный VPN для Android на Kotlin с нативным интерфейсом (Material 3), полностью на русском языке.
Маршрутизация трафика берётся из PAC-сценария AntiZapret (`proxy.pac`): домены и IP-адреса из списка идут через
прокси, всё остальное — напрямую.

## Возможности

- **Одна кнопка** — включить или выключить VPN.
- **PAC без изменений.** Сценарий `app/src/main/assets/proxy.pac` исполняется как есть встроенным движком
  QuickJS (`FindProxyForURL`, `dnsResolve`, `isInNet` и т. д.). PAC можно обновлять из интернета
  (по умолчанию раз в сутки) и возвращаться к встроенному.
- **Локальный SOCKS5-прокси с логином и паролем.** Логин (`zastra_xxxxxx`), пароль (24 символа) и порт создаются
  автоматически при первом запуске криптостойким генератором. Адрес, логин, пароль и ссылку
  `socks5://логин:пароль@127.0.0.1:порт` можно посмотреть и скопировать в «Настройках». Прокси слушает только
  `127.0.0.1`, без авторизации не работает и доступен, пока включён VPN. Новые данные создаются там же.
- **Выбор приложений**, для которых работает VPN, **включая системные**: «Все», «Только эти», «Кроме этих»,
  поиск, переключатель показа системных приложений.
- **DNS:** обычный (UDP/TCP) или **DoH** (DNS через HTTPS). По умолчанию — DoH Google DNS. Можно выбрать Cloudflare,
  Quad9, AdGuard, указать свой адрес DoH, а также свои основные и запасные серверы обычного DNS.
  Настройки DNS применяются «на лету», без переподключения.
- **Журнал** работы для диагностики (копирование и очистка).

## Как это устроено

```
приложения ─▶ TUN ─▶ hev-socks5-tunnel ─▶ локальный SOCKS5 (127.0.0.1, логин/пароль)
                                                │
                                   PAC (QuickJS) решает, как идти:
                                   HTTPS-прокси / PROXY / SOCKS5 / напрямую
```

- `hev-socks5-tunnel` (tun2socks) принимает пакеты из TUN-интерфейса. Его «подменный» DNS (mapdns) возвращает
  приложениям временные адреса и передаёт SOCKS5-серверу **имя хоста**, поэтому PAC видит домен, а не только IP.
- Собственный SOCKS5-сервер (`core/socks`) поддерживает CONNECT и UDP ASSOCIATE, спрашивает у PAC маршрут и
  соединяется по цепочке из PAC (`HTTPS host:port; PROXY host:port; DIRECT`), пробуя варианты по порядку.
  Недоступные прокси временно откладываются.
- Все исходящие сокеты приложения защищены `protect()` и не попадают обратно в туннель; само приложение Zastra
  из VPN исключено.
- DNS-запросы приложений обрабатываются внутри (`core/dns`) выбранным способом (DoH или обычный DNS) с кэшем.

Структура проекта:

| Путь | Что там |
|---|---|
| `app/src/main/java/app/zastra/vpn/core` | Чистая JVM-логика: PAC, DNS, SOCKS5 (покрыта модульными тестами) |
| `app/src/main/java/app/zastra/vpn/vpn` | `VpnService`, конфиг tun2socks, состояние |
| `app/src/main/java/app/zastra/vpn/ui` | Экраны: главный, настройки, приложения, журнал |
| `app/src/main/jni` | Сборка нативных библиотек: hev-socks5-tunnel и QuickJS-ng (исходники включены) |
| `app/src/main/assets/proxy.pac` | Встроенный PAC |

## Сборка

### GitHub Actions (рекомендуется)

1. Создайте репозиторий на GitHub и загрузите в него содержимое этой папки.
2. Откройте вкладку **Actions** — сборка запустится при каждом `push`. Готовый APK лежит в артефактах запуска.
3. Чтобы получить релиз, создайте тег: `git tag v1.0.0 && git push --tags`. APK прикрепится к релизу автоматически.

**Подпись своим ключом** (необязательно). Без ключа APK подписывается отладочным ключом — он устанавливается, но при
смене ключа обновление поверх придётся делать через удаление. Чтобы подписывать своим ключом, добавьте секреты
репозитория (Settings → Secrets and variables → Actions):

| Секрет | Значение |
|---|---|
| `ZASTRA_KEYSTORE_BASE64` | файл `.jks` в base64: `base64 -w0 my.jks` |
| `ZASTRA_KEYSTORE_PASSWORD` | пароль хранилища |
| `ZASTRA_KEY_ALIAS` | псевдоним ключа |
| `ZASTRA_KEY_PASSWORD` | пароль ключа |

### Локально

Нужны JDK 17, Android SDK (платформа 35, build-tools 35.0.0) и NDK `27.2.12479018`.

```
./gradlew testDebugUnitTest      # модульные тесты
./gradlew assembleRelease        # app/build/outputs/apk/release/
```

Для подписи локально положите рядом с `build.gradle.kts` файл `keystore.properties`
(`storeFile`, `storePassword`, `keyAlias`, `keyPassword`) или задайте те же значения переменными окружения
`ZASTRA_KEYSTORE_FILE`, `ZASTRA_KEYSTORE_PASSWORD`, `ZASTRA_KEY_ALIAS`, `ZASTRA_KEY_PASSWORD`.
Файл `keystore.properties` исключён из git.

Минимальная версия Android — 8.0 (API 26). APK универсальный: armeabi-v7a, arm64-v8a, x86, x86_64.

## Замечания и ограничения

- **IPv6** не маршрутизируется через туннель. Запросы AAAA в режиме подменного DNS получают пустой ответ, поэтому
  приложения обычно используют IPv4.
- **UDP** (в том числе QUIC/HTTP3) к адресам, которые по PAC должны идти через прокси, отбрасывается — браузеры
  возвращаются на TCP. Запросы DNS по UDP на порт 53 обрабатываются встроенным DNS.
- Прокси из PAC принадлежат сервису AntiZapret. Приложение использует только те прокси, которые перечислены в PAC.
  Сервис просит не обращаться за PAC чаще раза в минуту — приложение это соблюдает.
- Если PAC недоступен по адресу по умолчанию (`https://p.thenewone.lol:8443/proxy.pac`), укажите свой адрес
  в «Настройках» или пользуйтесь встроенным PAC.
- Режим «Только эти» требует хотя бы одного отмеченного приложения; изменения в списке приложений применяются
  при следующем подключении.
